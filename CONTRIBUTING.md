# Contributing

- Add a profile by copying `profiles/_template/`; share only a hand-made seed list, never scraped data or personal details.
- Add a board adapter with a parser, a probe and a test using a recorded fixture.
- Run `pytest` and `ruff check .` before opening a PR.
- Keep the safety rules in `references/safety.md`: no auto-submit, no CAPTCHA bypass, public endpoints only.
