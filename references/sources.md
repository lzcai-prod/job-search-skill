# Where to get a list of employers

Check each source's current terms before bulk-collecting anything. Prefer official exports, public pages the user opens, and web search. Do not redistribute scraped lists in a public repo.

| Source | Good for | Cost / terms note |
|---|---|---|
| The user's own dream list | Taste, the most valuable input | Free |
| Role-specific job boards (for design: Dribbble Jobs, Behance, Coroflot, AIGA) | Who actually hires this role | Free to browse; do not bulk-scrape |
| General job boards and startup boards (LinkedIn, Wellfound, Built In, YC Work at a Startup) | Breadth, startups | Terms restrict scraping |
| Web search of ATS domains, e.g. `site:boards.greenhouse.io "product designer"` | Finding boards by role | Free |
| Investor portfolio pages and funding databases | Funded startups | Bulk export usually paid |
| Award and quality lists (design awards, "best places to work" lists) | Tiering by quality | Free to read |
| School career-centre employer lists and alumni networks | Warm employers | Free, requires login |
| Government sponsorship data (US DOL LCA disclosures) | Employers that sponsor, if the user needs it | Public data |

**Method:** the user writes 20 to 30 dream companies, the agent expands to about 300 using these sources, the user prunes. Record bucket and tier for each.
